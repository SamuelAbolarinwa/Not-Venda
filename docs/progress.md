- Token verification through Supabase Auth, current active membership checks and user-token database operations; no elevated application key. Bounded lists, safe request IDs/error envelopes, redacted minimal logging, request limits, liveness/readiness and same-origin Vite proxy.

- Two disposable demo shops and five verified fixture identities (owner/staff for each shop plus inactive staff), same product at different prices.
- Implemented OpenAPI plus separate planned partner contracts; five-packet plan, architecture, decisions, environment templates and staging procedure.
- GitHub Actions workflow for application checks and disposable local Supabase security/integration checks, without production secrets. Workflow has NOT run on GitHub.
